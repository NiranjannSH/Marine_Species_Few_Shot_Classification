# Supervised Contrastive Learning & Episodic Test-Time Adaptation for Few-Shot Fish Classification

This repository presents an end-to-end framework combining **Supervised Contrastive Pre-training (SupCon)** with **Episodic Test-Time Adaptation (TTA)** for fine-grained fish visual classification.

---
