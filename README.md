# 🐟 Supervised Contrastive Representation Learning for Few-Shot Classification of Marine Species

This repository contains the implementation of a two-stage framework combining **Supervised Contrastive Pre-training (SupCon)** with **prototype-initialised Test-Time Adaptation (TTA)** for few-shot classification of marine species on three underwater datasets.

---

## 📊 Dataset Availability & Sources

| Dataset | Source / Download Link | Description | Processing Note |
| :--- | :--- | :--- | :--- |
| **Croatian** | [Kaggle Dataset](https://www.kaggle.com/datasets/ashfaqsyed/croatian-fish-dataset) | Underwater fish species from the Adriatic Sea. | Auto-downloaded to `data/raw` and moved to `data/processed`|
| **Fish4Knowledge (F4K)** | [University of Edinburgh Source](https://homepages.inf.ed.ac.uk/rbf/Fish4Knowledge/GROUNDTRUTH/RECOG/) | Verified underwater fish images from live video feeds in Taiwan. |  Auto-downloaded to `data/raw/` and moved to `data/processed`|
| **Aqua20** | [AQUA20 GitHub Repository](https://github.com/taufiktrf/AQUA20) | Aquatic species benchmark for complex underwater environments (the human diver category is excluded). |  Auto-downloaded and saved to `data/processed`|

**Class splits.** For each dataset, the class folder names are sorted alphabetically and shuffled with `random.Random(42)`; the shuffled list is divided into base, validation and novel (test) classes:

| Dataset | Base | Validation | Novel (test) | Test setting |
| :--- | :---: | :---: | :---: | :--- |
| Croatian | 7 | 2 | 3 | 3-way |
| Fish4Knowledge | 16 | 2 | 5 | 5-way |
| Aqua20 | 12 | 2 | 5 | 5-way |

The class names of every split are printed at the start of each run and listed in the Supplementary Material of the paper.

## ⚙️ Protocol and Hyperparameters

All hyperparameters are set in `config.py` and were selected on the **validation classes only**; the novel classes are used once, for the final test.

| Stage | Setting | Value |
| :--- | :--- | :--- |
| Input | resolution / normalisation | 84 × 84, ImageNet mean and standard deviation |
| Stage 1 (SupCon pre-training) | backbone | ResNet-18, ImageNet weights (`IMAGENET1K_V1`), 512-d pooled features |
| | projection head | 512 → 512 → 256 → 128 (BatchNorm + ReLU), discarded after Stage 1 |
| | optimiser | AdamW, learning rate 1e-4, weight decay 1e-4, cosine schedule |
| | temperature τ | 0.15 |
| | batch / epochs | 128 images × 2 augmented views, 100 epochs |
| | checkpoint | validated after **every** epoch on 600 fixed 2-way episodes; the best checkpoint is kept separately for 1-shot and 5-shot |
| Stage 2 (test) | episodes | 600 fixed test episodes per dataset and shot, 5 query images per class |
| | classifier | cosine classifier initialised from the l2-normalised support prototypes |
| | adaptation | 17 SGD steps, momentum 0.9, classifier LR 0.05, encoder LR 0.005, support set only, BatchNorm statistics frozen, encoder reset for every episode |
| | reported | accuracy **without** (0 steps) and **with** (17 steps) adaptation, mean ± 95% confidence interval |

**Leak-free episodes.** `make_episodes.py` builds the validation and test episodes once. Pixel-identical images are kept only once per class, images that also occur in another class are removed, and episodes are sampled without replacement, so no identical image tensor appears more than once within an episode. Every saved file is reloaded and verified.

## 🚀 Execution Workflow

### Step 1: Install Dependencies
```bash
git clone https://github.com/NiranjannSH/Marine_Species_Few_Shot_Classification.git
cd Marine_Species_Few_Shot_Classification
pip install -r requirements.txt
```

### Step 2: Prepare Datasets
```bash
python prepare_data.py
```

> **Note on `DOWNLOAD_DATA` configuration:**
> * Inside `prepare_data.py`, set **`DOWNLOAD_DATA = True`** to download the raw datasets automatically via `kagglehub` and Hugging Face.
> * If you have already downloaded the datasets manually, set **`DOWNLOAD_DATA = False`** and place the uncompressed raw files in `data/raw/croatian` and `data/raw/fish4knowledge`.

### Step 3: Build the Fixed Episodes
```bash
python make_episodes.py
```
This writes `data/episodes/<dataset>_{val,test}_{1,5}shot_episodes.pt` (plus a `_files.json` listing the image files of every episode). Existing files are not overwritten unless `--force` is given.

### Step 4: Run Pre-Training and Evaluation
```bash
python main.py
```

`main.py` detects the available GPUs, runs one dataset per GPU, and writes the logs, the best-validation checkpoints and the result tables (accuracy without and with adaptation, training and inference cost) to `./checkpoints/`.
