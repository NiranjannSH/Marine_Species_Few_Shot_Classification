# 🐟 Supervised Contrastive Learning with Few-Shot for Fish Classification

This repository contains the implementation of a two-stage framework combining **Supervised Contrastive Pre-training (SupCon)** with **Episodic Test-Time Adaptation (TTA)** for fine-grained fish species classification across underwater datasets.

---

## 📊 Dataset Availability & Sources

| Dataset | Source / Download Link | Description | Processing Note |
| :--- | :--- | :--- | :--- |
| **Croatian** | [Kaggle Dataset](https://www.kaggle.com/datasets/ashfaqsyed/croatian-fish-dataset) | Underwater fish species from the Adriatic Sea. | Auto-downloaded or pulled from `data/raw/croatian` |
| **Fish4Knowledge (F4K)** | [University of Edinburgh Source](https://homepages.inf.ed.ac.uk/rbf/Fish4Knowledge/GROUNDTRUTH/RECOG/) | Verified underwater fish images from live video feeds in Taiwan. | Auto-downloaded or pulled from `data/raw/fish4knowledge` |
| **Aqua20** | [AQUA20 GitHub Repository](https://github.com/taufiktrf/AQUA20) | Aquatic species benchmark for complex underwater environments. | Automatically fetched via Hugging Face (`taufiktrf/AQUA20`) |

```text
fish-fewshot-supcon/
├── data/
│   ├── raw/                   # Source archives/folders for Croatian & Fish4Knowledge
│   └── processed/             # Formatted species directories generated by prepare_data.py
│       ├── croatian/
│       ├── fish4knowledge/
│       └── aqua20/
├── checkpoints/               # Saved model weights, execution logs & paper evaluation tables

├── models.py                  # ResNet18 Encoder, Projector, Cosine Classifier & SupCon Loss

├── trainer.py                 # Stage 1 (SupCon) & Stage 2 (TTA) pipeline execution logic

├── requirements.txt           # Project dependencies
└── README.md                  # Documentation
```

## 🚀 Execution Workflow

### Step 1: Install Dependencies
Clone the repository and install all required python dependencies:
```bash
git clone [https://github.com/your-username/fish-fewshot-supcon.git](https://github.com/your-username/fish-fewshot-supcon.git)
cd fish-fewshot-supcon
pip install -r requirements.txt
```

---

### Step 2: Prepare Datasets (Must be executed first!)
Run `prepare_data.py` to set up and format the dataset directories under `data/processed/`:

```bash
python prepare_data.py
```

> **Note on `DOWNLOAD_DATA` configuration:**
> * Inside `prepare_data.py`, set **`DOWNLOAD_DATA = True`** if you want the script to automatically download the raw datasets via `kagglehub` and Hugging Face.
> * If you have already downloaded the datasets manually, set **`DOWNLOAD_DATA = False`** and place your uncompressed raw files directly into `data/raw/croatian` and `data/raw/fish4knowledge`.

---

### Step 3: Run Model Pre-Training & Test-Time Adaptation
Once `prepare_data.py` completes and populates `data/processed/`, launch the main training orchestrator:

```bash
python main.py
```

`main.py` will automatically detect available GPUs, allocate datasets dynamically, and log all performance metrics, model weights, and formatted summary tables directly into `./checkpoints/`.
